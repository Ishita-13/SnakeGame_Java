# 🐍 Snake Game - Java

A simple and interactive Snake Game developed using Java Swing.

## 🎮 Features

- Snake movement using arrow keys
- Random food generation
- Snake grows after eating food
- Score tracking
- Wall collision detection
- Self-collision detection
- Game Over screen
- Restart functionality

## 🛠️ Technologies Used

- Java
- Java Swing
- AWT
- IntelliJ IDEA

## 🎯 Controls

| Key | Action |
|---|---|
| ⬆️ Up Arrow | Move Up |
| ⬇️ Down Arrow | Move Down |
| ⬅️ Left Arrow | Move Left |
| ➡️ Right Arrow | Move Right |
| Enter | Restart Game |

## ▶️ How to Run

### Using IntelliJ IDEA

1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Make sure JDK 17 or higher is installed.
4. Open `src/SnakeGame.java`.
5. Run the `main()` method.

### Using JAR

A compiled JAR file is available in the release section.

Run it using:

```bash
java -jar SnakeGame.jar
